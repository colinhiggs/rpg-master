This is the whole game. It is short on purpose: everything here fits in
one sitting, and anything not covered is a question for the table
rather than a gap to be patched with more rules.

Read it in order the first time. After that, use the contents above —
every rule is self-contained enough to be looked up on its own, and the
in-game help shows the same text you are reading now.
